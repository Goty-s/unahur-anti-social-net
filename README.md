# 👾 Anti-social-net 👾
<img width="700" height="350" alt="banner" src="image-1.png" /> 

### UnaHur Anti-Social Net es una aplicación web desarrollada para facilitar el intercambio de contenido y opiniones dentro de una comunidad de manera ágil y ordenada. Nuestro objetivo es ofrecer una experiencia intuitiva enfocada en lo esencial: compartir y dialogar.

### A través de la plataforma, las personas usuarias pueden registrarse, iniciar sesión, navegar por el muro de publicaciones, crear sus propios posteos acompañados de imágenes y participar activamente mediante comentarios.

## Tecnologías utilizadas.
* React.
* Vite.
* React Router.
* React Bootstrap.
* Bootstrap Icons.
* CSS Modules.
* Context API de React.
* Git y GitHub.

## 💻 Instrucciones para instalar y correr el proyecto.

1. Copiar el link de code en Github de la aplicación y de la API.
2. Utilizando Gitbash clonar ambos repositorios por separado usando el siguiente código: 
```bash
git clone +Link code+
```
3. Abrir la carpeta de la API en Visual Studio Code.
4. Abrir la terminal del Visual Studio Code.
5. Instalar las dependencias escribiendo en la terminal: 
```bash
npm i
```
6. Crear y poblar la base de datos con datos de ejemplo:
```bash
node seed.js
```
7. Correr el proyecto escribiendo en la terminal:
```bash
npm run dev
```
8. Abrir la carpeta de la aplicación en Visual Studio Code.
9. Abrir la terminal del Visual Studio Code.
10. Instalar las dependencias escribiendo en la terminal: 
```bash
npm i
```
11. Correr el proyecto escribiendo en la terminal:
```bash
npm run dev
```
